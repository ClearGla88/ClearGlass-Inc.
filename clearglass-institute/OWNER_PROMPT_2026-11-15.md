# Owner's prompt of 2026-11-15: what it asked for and where it went

> **Status notice.** ClearGlass Institute is a proposed organization. It has not been incorporated. ClearGlass Institute is not currently a registered charity with the Canada Revenue Agency. Donations are not eligible for official charitable tax receipts. Documents in this folder are drafts and templates, not legal advice. Signed originals belong in the minute book, not in this repository.

On 2026-11-15 the owner supplied a twelve-phase prompt for a complete formation and compliance program for ClearGlass Institute, "starting from zero". The package was not at zero: documents 1 to 13 already covered most phases. Each phase was compared with the package. Where the package had a gap, the gap was filled, and every new legal rule was checked against an official or published source first ([L-44] to [L-52]). This page records the result, so the same ground is not covered twice.

The prompt itself is not stored here. It names the founder; this repository is public, so the package refers to roles, not people.

## Not taken, and why

| The prompt says | This package says | Rule or reason |
|---|---|---|
| Start from zero; do not assume the entity exists | Correct that it does not exist; but the package already exists, so it was extended, not rewritten | `STATUS.md` |
| Act as an attorney, CPA and corporate secretary | Nothing here is legal, tax or accounting advice. Every legal question is tagged for a qualified person | README, "Not legal advice" |
| Name the founder | Roles only. The repository is public | README, "Privacy" |
| Public foundation and private foundation as structures to choose | They are categories that tests in the Income Tax Act decide, not choices | [L-44] [L-45] |
| "Corporate seal" and "share restrictions" required or recommended | No seal requirement was found in the sources read; an Ontario not-for-profit corporation has no share capital | Doc 15 section A; [L-43] |
| Business number registration as a filing step | Possibly assigned on incorporation; confirm before applying | [L-26] |
| "Director agreements" | A commitment letter, not a contract: directors are not paid for acting as directors | [L-30]; doc 16.2 |
| "Membership programs" | A supporter list unless the board wants supporters to vote: members under the Act have voting rights | [L-41]; doc 13 B13 |
| Thirty-plus policies | Each one written when the activity it governs begins; thirteen are needed before the first employee, eight are not needed yet | Doc 15 |
| Cost and deadline for every item | Given only where a source states it. Other fees are marked [CONFIRM] | `LEGAL_VERIFICATION.md` |
| 30, 60, 90-day and one-year plan with dates | Dates count from incorporation, which has not happened. The 14-day and 90-day plans stand; doc 17 and the `calendar` command give the first year | Docs 9, 10, 17 |
| US and international operations | Not verified. Recorded as questions for counsel; no activity outside Canada and no fundraising outside Ontario in year one is recommended | Doc 14.5; doc 13 C12 |
| A "model governance standard" | The Institute does not build or host models | Doc 15 section E |
