§ 05 — Technical Specifications
Architecture & Deployment
Deployment ModelSingle self-contained HTML file (65KB). Zero server infrastructure. Runs directly in any modern browser via file:// or HTTP(S). No npm, no Node.js, no Python required.
External DependenciesChart.js 4.4.1 (CDN — optional offline bundle available). Google Fonts (JetBrains Mono + Rajdhani — optional local font fallback). Both can be inlined for air-gapped environments.
Browser CompatibilityChrome 90+, Edge 90+, Firefox 88+, Safari 14+. Fully responsive — mobile, tablet, desktop, ultrawide.
AI Engine — NEXUS COREAutonomous rule-based intelligence engine. Processes 8+ query categories: full briefing, signal analysis, sentiment decode, influence topology, forecast projection, crisis sweep, business matrix, threat landscape. Zero API calls. Instant response.
AI Engine — Claude APIOptional upgrade. Connects directly to Anthropic's claude-sonnet-4-20250514 model via browser-side API call. API key stored in-session only — never transmitted to third parties. 10-message conversation history maintained.
Data IntegrationAccepts JSON output from any NEXUS-compatible PS1 scanner. Drop JSON into NEXUS_DATA object. Immediate recalculation of all charts, metrics, AI context, and ticker. Compatible with Burlington Nexus PS1, NetShield Pro, AEGIS, Aurora RT data formats.
Location TargetingUnlimited worldwide target locations. Enter any city, region, or country. Scan animation sequence (3.8 seconds). All dashboard labels, AI context, ticker, footer automatically update to new target. No code changes required.
File Size65KB (HTML). Under 200KB when all external resources cached. Sub-1-second load on modern hardware. No webpack, no build step.
Air-Gap DeploymentAvailable on request. Fully inlined version (Chart.js + fonts embedded) for classified or restricted network environments. Contact Clear Glass for air-gap edition.
Data PrivacyAll data processing occurs client-side in the browser. No telemetry. No tracking. No server-side logging. API key never leaves the browser session. Compliant with PIPEDA client-side data handling requirements.
Technology Stack
HTML5 Vanilla JavaScript (ES2020) CSS3 Custom Properties Chart.js 4.4.1 Anthropic Claude API (optional) Google Fonts CDN PowerShell Data Pipeline JSON Data Schema CSS Grid + Flexbox Web Animations API
§ 06 — Compliance & Legal Framework
Regulatory Alignment
NEXUS is designed for responsible intelligence operations within Canadian and international legal frameworks. Clear Glass Inc maintains full compliance documentation available to enterprise clients.
🇨🇦
PIPEDA
Personal Information Protection and Electronic Documents Act. NEXUS processes only publicly available social data. Client-side architecture ensures no personal data transits Clear Glass infrastructure.
⚖️
Criminal Code S.342.1
Canadian Computer Fraud provisions. NEXUS operates exclusively on public API data and user-provided inputs. No unauthorized system access. Full legal opinion available to enterprise clients.
🛡️
SOC 2 Alignment
Platform architecture designed to SOC 2 Type II principles: Security, Availability, Processing Integrity, Confidentiality. Enterprise clients receive SOC 2 alignment documentation for vendor assessment processes.
🌐
GDPR Compatible
For EU deployment: NEXUS processes publicly available data only. No personal data storage. Client-side processing model inherently compatible with GDPR data minimization and purpose limitation principles.
🔐
API Key Security
When Claude API mode is enabled, the API key is stored in-session memory only (never localStorage, never transmitted). Session memory cleared on browser close. No Clear Glass server ever receives API credentials.
📋
Data Provenance
All intelligence data is sourced from public social platforms via authorized API access (Twitter API, Reddit API, Google Places API). Full data provenance documentation available for enterprise audit requirements.
